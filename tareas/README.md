# Tareas de la migración de Cobranzas

Plan completo: documento "Plan de migración de Cobranzas".

Cada tarea es un archivo `TNN.md` con esta estructura:

- **Objetivo**: qué debe quedar funcionando.
- **Depende de**: tareas que deben estar integradas antes.
- **Archivos a tocar** y **archivo modelo** a copiar.
- **Criterios de terminado**: comprobables (tests, comandos, comportamiento).
- **Fuera de alcance**: lo que no se debe hacer.

Responsables: las tareas marcadas "OpenCode" se hacen en una copia limpia del repositorio; Claude revisa el diff antes de integrarlo.
